# Cinema Manager 

Кросплатформовий застосунок на базі .NET MAUI для управління кінозалами та розкладом сеансів. Проєкт є фінальною реалізацією курсового проєкту, перебудованого згідно з принципами багатошарової архітектури та патерну MVVM.

## Архітектура та структура проєкту

Рішення розділене на 4 логічні проєкти для забезпечення чіткого розподілу відповідальностей:

### 1. `CinemaManager.Models` (Шар сутностей)
* **Entities**: Базові моделі даних CinemaHall.cs та MovieSession.cs.
* **Enums:** Перерахування для типізації даних Genre.cs та HallType.cs.

### 2. `CinemaManager.DB` (Шар доступу до даних)
Відповідає виключно за роботу зі сховищем даних:
* **Database:** Використовується реальна база даних SQLite. Для роботи з нею реалізовано AppDbContext.cs та DbContextFactory.cs.
* **Initialization:** Клас DatabaseInitializer.cs забезпечує заповнення бази початковими даними (3 зали та 12 сеансів) лише при першому запуску застосунку.
* **ICinemaRepo:** Інтерфейс для забезпечення принципу Dependency Inversion.
* **CinemaRepo:** Клас репозиторію, методи якого виконують CRUD операції та повертають доменні моделі. Реалізовано каскадне видалення: при видаленні залу видаляються всі його сеанси.

### 3. `CinemaManager.Services` (Рівень сервісів)
* **DTO:** Файли CinemaHallDTOs.cs та MovieSessionDTOs.cs містять спеціалізовані моделі для різних потреб UI: ListDTO, DetailsDTO, CreateDTO та UpdateDTO.
* **ICinemaService.cs:** Інтерфейс сервісного рівня, що описує всі доступні бізнес-операції.
* **CinemaService.cs:** Отримує дані з репозиторію та конвертує їх у DTO-моделі. Вся взаємодія зі сховищем є асинхронною.

### 4. `CinemaManager.MAUI` (Графічний застосунок)
Рівень представлення, реалізований на базі патерну MVVM:
* **ViewModels:** Класи MainViewModel.cs, HallDetailsViewModel.cs, SessionDetailsViewModel.cs, а також нові HallEditViewModel.cs та SessionEditViewModel.cs для операцій редагування. Використано CommunityToolkit.Mvvm для реактивного програмування.
* **Views:**Сторінки MainPage, HallDetailsPage, SessionDetailsPage та нові форми HallEditPage і SessionEditPage. Файли .xaml.cs містять лише ініціалізацію та задання BindingContext.
* **Dependency Injection:** Впровадження залежностей (Singleton для сервісів та Transient для сторінок/ViewModels) реалізовано у MauiProgram.cs.
* **Асинхронний UI:** Реалізовано відображення індикатора прогресу та блокування операцій під час виконання асинхронних запитів до бази даних.

## Основний функціонал
* **Повний CRUD:** Можливість створення, перегляду, редагування та видалення як кінозалів, так і сеансів.
* **Навігація:** Повна підтримка переходів між сторінками через AppShell (Список залів -> Деталі залу -> Деталі сеансу/Редагування) з можливістю повернення назад. Вибір конкретного залу користувачем. Перехід до детальної інформації про кожен сеанс (у версії MAUI).
* **Пошук та сортування:** Реалізовано можливості фільтрації та впорядкування списків сутностей обох рівнів.
* **Ізоляція:** UI взаємодіє виключно з сервісами та DTO-моделями, не маючи прямого доступу до репозиторіїв чи DB-моделей.
* **Автоматизація:** Автоматичне підвантаження сеансів для обраного залу та підрахунок загальної тривалості фільмів.
* **Цілісність:** Гарантоване видалення пов'язаних даних при видаленні основного об'єкта.

## Як запустити проєкт
1. Склонуйте репозиторій на свій комп'ютер.
2. Відкрийте файл рішення `CinemaManager.sln` у Visual Studio.
3. Виберіть стартовий проєкт: натисніть правою кнопкою на `CinemaManager.MAUI` -> **Set as StartUp Project**.
4. Натисніть `F5` або кнопку `Start` для запуску застосунку.
5. База даних: Файл cinema.db буде автоматично створено за шляхом AppData/Local/Packages/[Назва_Проєкту]/LocalState/ (для Windows).
6. Для коректної роботи потрібен встановлений .NET 9.
